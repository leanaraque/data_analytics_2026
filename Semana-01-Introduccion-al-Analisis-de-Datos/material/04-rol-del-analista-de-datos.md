# 4. Rol del Analista de Datos

> Ya conocés el ecosistema; ahora conocés tu lugar dentro de él.

¿Alguna vez te has preguntado quién está detrás de las decisiones basadas en datos dentro de una empresa? El **analista de datos** es el profesional clave que transforma datos crudos en información útil para impulsar estrategias y operaciones.

## Funciones clave
- **Recolección de datos:** obtiene datos de diversas fuentes —bases de datos, archivos, APIs o plataformas digitales.
- **Limpieza y preparación:** depura y transforma los datos para asegurar su calidad y consistencia, eliminando errores o valores atípicos.
- **Análisis exploratorio:** examina los datos para identificar patrones, tendencias y relaciones relevantes.
- **Visualización y comunicación:** presenta los hallazgos mediante gráficos, reportes o dashboards para facilitar la comprensión de quienes toman decisiones.

> **Nota:** el analista debe entender el **contexto del negocio** para interpretar correctamente los datos y generar insights accionables.

## Herramientas principales
- **SQL:** lenguaje estándar para consultar y manipular bases de datos relacionales. Esencial para extraer datos específicos.
- **Python y R:** lenguajes usados para análisis estadístico, modelado y visualización avanzada.
- **Plataformas de Business Intelligence (BI):** herramientas como Power BI, Tableau o Looker Studio para crear dashboards interactivos y reportes visuales.

| Herramienta | Uso principal | Ejemplo de aplicación |
|-------------|---------------|-----------------------|
| **SQL** | Consultas y extracción de datos | Obtener ventas por región en un periodo específico |
| **Python** | Análisis estadístico y automatización | Calcular tendencias de comportamiento de clientes |
| **R** | Modelado estadístico y visualización | Realizar análisis de segmentación de mercado |
| **Power BI** | Visualización y reportes dinámicos | Crear dashboard de indicadores clave de rendimiento |

## Flujo de trabajo típico

```mermaid
flowchart LR
    A[Recolección de Datos] --> B[Limpieza y Preparación]
    B --> C[Análisis Exploratorio]
    C --> D[Visualización y Comunicación]
```

Este flujo asegura que los datos sean **confiables** y que los resultados sean **claros y útiles** para la organización.

## En la práctica
El analista de datos trabaja en estrecha colaboración con equipos de marketing, operaciones, finanzas y tecnología para entender sus necesidades y traducirlas en preguntas analíticas. Por ejemplo, un analista en marketing puede usar **SQL** para extraer datos de campañas, **Python** para analizar el comportamiento de los clientes y **Power BI** para presentar resultados a su equipo.

El conocimiento de plataformas BI facilita la creación de reportes automáticos que mantienen a la organización informada en tiempo real. Este rol es clave para que las empresas tomen decisiones basadas en evidencia y mejoren su competitividad.
