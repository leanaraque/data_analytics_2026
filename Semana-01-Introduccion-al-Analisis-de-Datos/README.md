# Semana 1 — Introducción al Análisis de Datos

> Primera unidad del curso. Todo lo que viene — SQL, ETL, DAX, dashboards — necesita este piso conceptual.

## 🎯 Objetivos de aprendizaje
Al finalizar esta semana serás capaz de:
- Distinguir con claridad entre **datos** e **información** y entender cómo el contexto los transforma.
- Comprender el **proceso y el valor** del análisis de datos, del dato a la decisión.
- Ubicar tu rol en el ecosistema **BI / Data Analytics / Data Science**.
- Describir las **funciones y herramientas** del analista de datos.
- Reconocer las **tecnologías** del ciclo de vida del dato (bases de datos, ETL/ELT, data lakes, visualización).
- Diferenciar una **base de datos** de un **dataset**.

## 📦 Entregable de la semana (¡esto cuenta para la nota!)

> **M1 — Pre-entrega: Brief del proyecto RetailPro** · [Ver consigna completa →](./entregable/README.md)

**¿En qué consiste, en una frase?** Antes de tocar ninguna herramienta, definís **el problema de negocio** de RetailPro (una distribuidora de tecnología), sus **fuentes de datos**, las **preguntas** que querés responder y los **KPIs** iniciales. Es la primera piedra del proyecto que vas a construir durante **todo el curso**.

**¿Qué entregás?** Un único archivo **PDF o DOCX** con **5 secciones**, subido directo en la plataforma.

| Sección | Ejemplo rápido |
|---------|----------------|
| 1. Problema de negocio | *"¿Por qué las ventas de la región Norte cayeron un 15% el último trimestre y qué categoría lo explica?"* (diagnóstica, no descriptiva) |
| 2. Fuentes de datos | Tablas `clientes`, `productos`, `ventas`, `territorios` y qué guarda cada una. |
| 3. Preguntas de análisis | 4–6 preguntas concretas que el dashboard debería responder. |
| 4. KPIs | Ej.: *Total Ventas* = `SUM(total_venta)`. Al menos 4, con nombre, descripción y fórmula conceptual. |
| 5. Boceto del dashboard | Un esquema simple (papel, PowerPoint o Canva) de la pantalla principal, incluido como imagen. |

> ⚠️ **Ojo:** este entregable (RetailPro) **sí es evaluable**. No confundir con la práctica guiada *CoffeeInsight*, que es opcional y **no** suma nota.

**Checklist de entrega:**
- [ ] 1 archivo único en **PDF o DOCX**.
- [ ] Incluye las **5 secciones**.
- [ ] El **boceto** va como imagen dentro del documento.
- [ ] Subido directo en la plataforma.
