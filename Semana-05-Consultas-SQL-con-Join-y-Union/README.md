# Semana 5 — Consultas SQL con Join y Union

> Combinar información que vive en varias tablas para responder preguntas más complejas.

## 🎯 Objetivos de aprendizaje
Al finalizar esta semana serás capaz de:
- Comprender cómo se relacionan las tablas entre sí.
- Combinar tablas con `INNER`, `LEFT`, `RIGHT` y `FULL JOIN`.
- Unir resultados de consultas con `UNION` y `UNION ALL`.
- Escribir subconsultas para resolver problemas por pasos.

## 📚 Contenidos
- Relaciones entre tablas.
- Tipos de `JOIN` (`INNER`, `LEFT`, `RIGHT`, `FULL`).
- Alias de tablas y columnas.
- `UNION` vs. `UNION ALL`.
- Subconsultas.
- Buenas prácticas de consultas.
