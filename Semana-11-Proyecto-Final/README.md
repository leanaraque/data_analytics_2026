# Semana 11 — Proyecto Final

> Integración de todo lo aprendido en un proyecto de análisis de datos de punta a punta: del dato crudo al dashboard que cuenta una historia.

## 🎯 Objetivos de aprendizaje
Al finalizar esta semana serás capaz de:
- Aplicar el ciclo completo de análisis: extracción, transformación, modelado, visualización y comunicación.
- Integrar SQL, Power Query, modelado, DAX y estadística en un mismo proyecto.
- Presentar y defender los hallazgos ante una audiencia.

## 📚 Contenidos
- Consigna del proyecto integrador.
- Criterios de evaluación (rúbrica).
- Entregables esperados.
- Presentación y defensa.

## 🧩 El proyecto integrador: RetailPro
A lo largo del curso vas a construir, módulo a módulo, el sistema de análisis de **RetailPro** (una distribuidora de tecnología). Cada pre-entrega suma al resultado final:

- **M1** — Brief analítico (problema, fuentes, preguntas, KPIs, boceto).
- **M2–M...** — Se irán detallando en cada módulo.
- **Final** — Dashboard ejecutivo + presentación de hallazgos.

## 📂 Contenido de la carpeta
| Recurso | Descripción |
|---------|-------------|
| `consigna/` | Enunciado y rúbrica del proyecto final. |
| `entregables/` | Espacio para los entregables. |
| `recursos/` | Plantillas y material de apoyo. |

> 🚧 El material se publica al acercarse el cierre del curso.
