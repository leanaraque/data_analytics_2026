# Semana 8 — Modelado Analítico y Cálculos Avanzados con DAX

> Diseñar el modelo de datos y crear cálculos potentes con DAX, el lenguaje de fórmulas de Power BI.

## 🎯 Objetivos de aprendizaje
Al finalizar esta semana serás capaz de:
- Diseñar un modelo de datos con esquema estrella.
- Crear y administrar relaciones entre tablas.
- Diferenciar columnas calculadas y medidas.
- Escribir cálculos con DAX usando contexto de filtro.

## 📚 Contenidos
- Modelo de datos y relaciones.
- Esquema estrella (hechos y dimensiones).
- Columnas calculadas vs. medidas.
- Introducción a DAX.
- Funciones clave: `SUM`, `CALCULATE`, `FILTER`.
- Contexto de fila y contexto de filtro.
- Introducción a *time intelligence*.
