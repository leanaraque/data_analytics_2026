# Semana 9 — IA Aplicada al Trabajo del Analista de Datos

> Usar la inteligencia artificial como copiloto para acelerar y mejorar el trabajo del analista.

## 🎯 Objetivos de aprendizaje
Al finalizar esta semana serás capaz de:
- Conocer herramientas de IA aplicables al análisis de datos.
- Generar y depurar consultas SQL y fórmulas DAX con ayuda de IA.
- Automatizar tareas repetitivas del flujo analítico.
- Aplicar la IA de forma crítica, ética y responsable.

## 📚 Contenidos
- IA generativa en el flujo del analista.
- *Prompt engineering* orientado a datos.
- IA dentro de Power BI (Copilot, preguntas y respuestas, insights).
- Buenas prácticas, límites y consideraciones éticas.
