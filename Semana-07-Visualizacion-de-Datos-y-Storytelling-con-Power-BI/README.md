# Semana 7 — Visualización de Datos y Storytelling con Power BI

> Convertir datos en historias claras: elegir la visualización correcta y comunicar hallazgos con impacto.

## 🎯 Objetivos de aprendizaje
Al finalizar esta semana serás capaz de:
- Elegir el tipo de visualización adecuado para cada mensaje.
- Construir gráficos e informes interactivos.
- Aplicar principios de diseño visual.
- Contar historias con datos (storytelling).

## 📚 Contenidos
- Tipos de visualizaciones y cuándo usarlas.
- Buenas prácticas de diseño visual.
- Filtros, segmentaciones e interactividad.
- Principios de storytelling con datos.
- Diseño de reportes y dashboards.
