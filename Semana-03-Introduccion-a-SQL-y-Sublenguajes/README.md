# Semana 3 — Introducción a SQL y Sublenguajes

> Primer contacto con SQL: el lenguaje estándar para hablar con las bases de datos y sus sublenguajes (DDL, DML, DCL, TCL).

## 🎯 Objetivos de aprendizaje
Al finalizar esta semana serás capaz de:
- Explicar qué es SQL y para qué se utiliza.
- Distinguir los sublenguajes DDL, DML, DCL y TCL.
- Crear y modificar bases de datos y tablas (DDL).
- Reconocer los tipos de datos más comunes.
- Preparar el entorno de trabajo (motor de base de datos y cliente).

## 📚 Contenidos
- ¿Qué es SQL?
- Sublenguajes: DDL, DML, DCL y TCL.
- Tipos de datos.
- `CREATE`, `ALTER`, `DROP`.
- Instalación y configuración del entorno.
