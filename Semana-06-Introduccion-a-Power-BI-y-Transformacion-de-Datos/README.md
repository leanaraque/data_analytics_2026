# Semana 6 — Introducción a Power BI y Transformación de Datos

> Primeros pasos con Power BI Desktop y limpieza de datos con Power Query (el proceso ETL).

## 🎯 Objetivos de aprendizaje
Al finalizar esta semana serás capaz de:
- Reconocer qué es Power BI y sus componentes.
- Conectar y cargar datos desde distintos orígenes.
- Limpiar y transformar datos con el Editor de Power Query.
- Entender el flujo ETL (Extraer, Transformar, Cargar).

## 📚 Contenidos
- ¿Qué es Power BI? Interfaz y componentes.
- Orígenes de datos y conexión.
- Editor de Power Query.
- Limpieza y transformación (tipos, columnas, filas).
- Pasos aplicados.
