# Semana 2 — Modelos y Diseños de Bases de Datos

> Fundamentos de las bases de datos relacionales: cómo se modelan, se relacionan y se normalizan los datos antes de consultarlos.

## 🎯 Objetivos de aprendizaje
Al finalizar esta semana serás capaz de:
- Explicar qué es una base de datos y un sistema gestor de bases de datos (SGBD).
- Diseñar un modelo entidad-relación (MER) a partir de un caso.
- Identificar entidades, atributos, relaciones y cardinalidades.
- Distinguir claves primarias y foráneas.
- Aplicar las formas normales (1FN, 2FN, 3FN).

## 📚 Contenidos
- Bases de datos relacionales y SGBD.
- Modelo Entidad-Relación (MER).
- Entidades, atributos y relaciones.
- Cardinalidad y tipos de relaciones.
- Claves primarias y foráneas.
- Normalización: 1FN, 2FN y 3FN.
